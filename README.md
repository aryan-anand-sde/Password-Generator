# 🔐 Password Generator

A sleek, responsive, and powerful web-based **Password Generator** built with pure HTML, CSS, and JavaScript. This tool allows users to generate secure, random passwords with customizable length and character sets.

---

## 🚀 Features

- **Customizable Length:** Generate passwords of any length (minimum 3).
- **Character Options:** Toggle between uppercase, lowercase, numbers, and special characters.
- **Instant Generation:** Fast and reliable password generation.
- **One-Click Copy:** Easily copy your generated password to the clipboard.
- **Responsive Design:** Works perfectly on desktops, tablets, and mobile devices.
- **Premium UI:** Featuring a vibrant, multi-colored border and a clean, modern aesthetic.

## 🛠️ Built With

- **HTML5:** For the structural foundation.
- **CSS3:** For modern styling and animations (including custom glassmorphism effects and vibrant borders).
- **JavaScript (Vanilla):** For the logic behind password generation and clipboard interaction.
- **Font Awesome:** For intuitive icons.

## ⚙️ How to Run Locally

1. **Clone the repository:**

   ```bash
   git clone https://github.com/your-username/Password-Generator.git
   ```

2. **Navigate to the project directory:**

   ```bash
   cd Password-Generator
   ```

3. **Open `index.html`:**
   Simply double-click the `index.html` file or use a live server extension in your favorite IDE (like VS Code).

---

## 🛡️ Security

This password generator runs entirely in your browser. No data is sent to any server, ensuring your generated passwords remain private and secure.
